# 芯希望 30054 · 比赛现场操作清单

**比赛最终版** `full_keyword_b4_competition_clear_large`  
**设备** AXU2CG-E、AN970、Vivado 2020.2、本机 J8 串口网关  
**启动镜像** [BOOT_QSPI_CHUNK.BIN](build/boot_competition/BOOT_QSPI_CHUNK.BIN) 已写入板载 QSPI 并通过读回校验。断电自启动仍在验证，现场可用已验证的 JTAG 下载流程。 [启动区烧录日志](build/boot_competition/program_qspi_chunk.log)

## 上台前

- [ ] **接线并上电。** 在断电状态下把 AN970 的 P4 接到 **J45**，对齐 Pin 1 和缺口。QSPI 启动档为 **SW1 的 1–4 位 ON、ON、OFF、ON**。打开板卡 **12 V** 电源，核对 AN970 是否出现竞赛待机界面。需要 JTAG 下载时按下方恢复步骤操作。

- [ ] **连接 J8。** 用 USB 数据线连接板上 **J8（PL UART）** 和电脑。在设备管理器的「端口（COM 和 LPT）」确认 CP210x 的端口号。本机验收用 **COM7，921600 8N1**。
- [ ] **打开上位机。** 网关已运行时直接打开下方页面。页面打不开时用另一窗口启动网关，保持该窗口运行；COM 号变化时替换命令中的 `COM7`。点击「连接 J8」，确认上方显示 **FPGA 实时识别**。

  ```powershell
  Set-Location 'D:/key_transformer_dot'
  python -u presentations/kwt_host_gui/board_server.py --port COM7 --listen 8771
  ```

  [打开比赛上位机](http://127.0.0.1:8771/presentations/kwt_host_gui/?board=1)

- [ ] **试跑一条。** 输入 **104**，点「选取」和「开始板端识别」。约 5 秒后，上位机应显示 **UP、12/12、标签一致**，AN970 应显示 **#104、波形、UP、青绿笑脸**。听一下电脑扬声器的录音播放。

## 评委抽样

1. 让评委点「随机抽取」，也可请评委指定 **000–599** 中的编号，再点「选取」。
2. 点「开始板端识别」。录音在电脑播放，特征和模型参数经 J8 下发。等待约 **5 秒**，再请评委选择下一条。
3. 对照两块屏的样本编号和关键词。AN970 以 **32 柱**显示波形，静音是平直基线。上位机「标签一致」对应青绿笑脸，「标签不一致」对应暖黄难过表情。
4. 抽到误判时保留结果。可用 **#408** 说明界面状态，它在实板上返回 **UNKNOWN**，真实标签为 **STOP**。

> 完整 W4 的 12 层编码器和分类头运行在 FPGA 上。编码有效计算约 **29 ms**，从下发到回传约 **5.3 s**。

## 快速恢复

按故障所在的环节处理，恢复后先试跑 **#104** 再继续随机抽样。

| 现场现象 | 立即处理 |
| --- | --- |
| 网页打不开或网关退出 | 用上面的命令启动网关，再打开页面。若端口 8771 已被本项目的网关占用，使用现有网关即可。 |
| 「连接 J8」失败或提示串口被占用 | 等当前任务结束，关闭占用串口的终端或另一套测试程序。检查 J8 数据线和设备管理器里的 COM 号，必要时以正确端口重启网关，然后在网页重新「连接 J8」。 |
| 识别超时 | 检查 J8 并重试 #104。仍超时就通过 JTAG 重新下载最终位流，再连接 J8。 |
| 板卡刚断过电 | 核对 SW1 处于 QSPI 启动档，上电后确认待机界面并重新连接 J8。 |
| JTAG 找不到 `xczu2` | 核对 12 V、JTAG 线和下载器 USB。关电检查 SW1 的 1–4 位，再上电下载。 |
| 电脑有结果，AN970 黑屏、白屏或卡在旧画面 | 先验证 #104 后切到 #408。实体屏仍无变化时，关电确认 J45 排针方向与排线接触，再上电测试。投屏可先继续展示真实 FPGA 回执。 |

**通过 JTAG 恢复最终版。** 关电后接上下载器，把 SW1 的 1–4 位全部拨到 ON，再上电执行以下命令。看到 `PROGRAMMED` 后重新连接 J8。回到 QSPI 启动时，关电将 SW1 第 3 位拨回 OFF，再上电。

```powershell
Set-Location 'D:/key_transformer_dot/FPGA_DATA/keyword_acc'
$vivado = 'E:/VIVADO/Vivado/2020.2/bin/vivado.bat'
& $vivado -mode batch -notrace -source scripts/hardware.tcl -tclargs full_keyword_b4_competition_clear_large
```

**完整识别仍异常。** 在下载终端执行下列命令，回退到已验收的上一版清晰界面。下载后重新连接 J8，仍可抽取全部 600 条。

```powershell
& $vivado -mode batch -notrace -source scripts/hardware.tcl -tclargs full_keyword_b4_competition_clear
```

**完整识别暂时恢复不了。** 若 JTAG 和 J8 可用，下载 MAC 保底，重新连接后只演示 **100、200、250、400** 的板端双项点积。若 J8 不可用但 JTAG 可用，下载 `mac` 位流，按板上的 **PL KEY** 依次演示 RIGHT、UP、LEFT、STOP。

```powershell
& $vivado -mode batch -notrace -source scripts/hardware.tcl -tclargs mac_uart_an970
# 需要脱离 J8 时改用下面一行
& $vivado -mode batch -notrace -source scripts/hardware.tcl -tclargs mac
```

**无法恢复实板链路。** 网页已接入时点「切回离线」。网关也不可用时，解压便携版并用 Chrome 或 Edge 打开 `KWT-STAR-Host/index.html`。现场说明切到了离线评测回放。实板恢复后再按正常流程下载和连接。 [离线便携版](../../presentations/KWT-STAR-Host-Portable.zip)
